Repo Guard options

Without a token GitHub allows 60 API requests/hour (~15 repo scans). With a token it is 5000/hour. Create a fine-grained token at github.com/settings/personal-access-tokens with Public repositories (read-only) and no account/repository permissions, and give it an expiry. The token is kept in this browser profile's extension storage and is only ever sent to api.github.com (and to raw.githubusercontent.com only for private repos).
Turn off to only scan when you click the Repo Guard pill - saves API quota. Results are cached for 6 hours either way. Manifests, install scripts, workflows and the README are scanned first, then source files closest to the repo root. File contents come from raw.githubusercontent.com, which does not count against the API limit.
